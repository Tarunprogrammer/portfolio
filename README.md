# EPPE TARUN — 3D Ultra-Cinematic Portfolio

An Awwwards-worthy, ultra-cinematic 3D portfolio website built for **Eppe Tarun** (Tarun Media) utilizing 100% free, open-source resources, real-time WebGL/Three.js spatial scenes, photorealistic CGI imagery, procedural Web Audio synthesis, and an interactive cyber terminal emulator.

---

## 🌟 Key Highlights & Visual Architecture

- **Real-Time 3D Holographic Cyber-Core**: Custom Three.js scene with faceted crystalline geometry, glowing geodesic wireframes, counter-rotating orbital rings, and dynamic particle galaxy responding to mouse physics.
- **Interactive 3D Skills Constellation**: Real-time WebGL neural node network connecting skills with glowing filaments that users can rotate in 3D.
- **Photorealistic Visual Assets**: Ultra-realistic 8K CGI render passes (`cyber_quantum_core.jpg`, `spatial_matrix_ui.jpg`, `cinematic_virtual_stage.jpg`) and cinematic bento grid gallery.
- **Procedural Web Audio Engine**: Zero-bandwidth, built-in ambient space drone and tactile holographic interface sound effects synthesized directly in code via the Web Audio API (with instant mute/unmute control).
- **Interactive Cyber Terminal CLI**: Functional command line emulator (`tarun@spatial-terminal`) supporting `help`, `skills`, `projects`, `contact`, `hire`, `matrix`, and `clear`.
- **Deep-Dive Case Study Modals**: Full architectural narrative, metrics, stack badges, and live demo links for flagship projects.
- **Interactive Contact Transmission**: One-click email copy with animated toast, social channels, and celebratory cyber confetti fireworks.

## 🚀 Quick Start (Local Development)

To run the portfolio locally on your machine:

```bash
# 1. Open project directory
cd "c:/TARUN MEDIA/Desktop/portfolio"

# 2. Start Vite development server
npm run dev
```

Open `http://localhost:5173` in your browser to experience the live 3D portfolio!

To build for production:

```bash
npm run build
```

## 🌐 100% Free Publishing & Deployment Guide

You can publish this portfolio completely free of charge with your name (`eppe-tarun`) using any of these 3 free hosting platforms:

### Option 1: Vercel (Recommended — 60-Second Setup)

1. Run the free Vercel deployment tool directly in your terminal:
   ```bash
   npx vercel
   ```
2. Follow the 3 prompts (login with GitHub or Email, set project name to `eppe-tarun`).
3. Your site will instantly be live at `https://eppe-tarun.vercel.app` with free SSL, automatic global CDN, and 100% uptime!

### Option 2: Netlify (Free 1-Click Publishing)

1. Deploy the pre-built `dist/` directory:
   ```bash
   npx netlify deploy --prod --dir=dist
   ```
2. Follow the prompt to log in and select site name `eppe-tarun`.
3. Your site is live at `https://eppe-tarun.netlify.app`!

### Option 3: GitHub Pages (Automated via GitHub Actions)

1. Push your repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: world-class 3d ultra-cinematic portfolio for Eppe Tarun"
   git branch -M main
   git remote add origin https://github.com/<YOUR-GITHUB-USERNAME>/eppe-tarun-portfolio.git
   git push -u origin main
   ```
2. Go to your GitHub Repository -> **Settings** -> **Pages**.
3. Under **Build and deployment** > **Source**, select **GitHub Actions**.
4. The included `.github/workflows/deploy.yml` will automatically build and publish your site at `https://<YOUR-GITHUB-USERNAME>.github.io/eppe-tarun-portfolio`!
